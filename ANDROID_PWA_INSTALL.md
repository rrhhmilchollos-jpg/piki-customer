# Instalación de Manduca Riders en Android

**Manduca Riders se instala como una PWA**, una aplicación web instalable. No requiere descargar un APK ni habilitar fuentes desconocidas: una vez publicada la versión actual, Chrome la instala de forma nativa en la pantalla de inicio y se abre en ventana independiente.

## Dirección de instalación

Después de publicar el checkpoint de esta versión, abre en Chrome para Android:

`https://mesagodeliv-gdrjgnii.manus.space/riders`

Inicia sesión con una cuenta rider y concede los permisos de ubicación solo si quieres recibir y compartir la posición operativa durante el turno.

## Pasos en Chrome para Android

| Paso | Acción |
|---|---|
| 1 | Abre la dirección de Riders en Chrome para Android. |
| 2 | Pulsa el menú de Chrome, identificado por los tres puntos verticales. |
| 3 | Selecciona **Instalar aplicación**; en algunas versiones se muestra como **Añadir a pantalla de inicio**. |
| 4 | Confirma **Instalar**. Android añadirá el icono verde de Manduca Riders a la pantalla de inicio y al cajón de aplicaciones. |
| 5 | Abre Manduca Riders desde ese icono. La aplicación funcionará en modo independiente y conservará recursos básicos para una conexión intermitente. |

La versión instalable incorpora manifiesto, iconos Android de 192 y 512 píxeles y un service worker. Las funciones de reparto, despacho, perfil, documentos, mapa, SOS y confirmación PIN/QR continúan conectadas al backend compartido.

> La pantalla de vista previa de desarrollo no es instalable ni compartible. Es necesario publicar primero el checkpoint desde la interfaz del proyecto para que la dirección anterior sirva la versión actual por HTTPS.
